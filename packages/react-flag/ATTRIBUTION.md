## Iran override

The Iran component uses the 1964–1980 Lion and Sun state flag from Wikimedia
Commons instead of the post-1980 emblem. The source artwork is in the public
domain and is preserved at `assets/overrides/ir.svg`.

Source: https://commons.wikimedia.org/wiki/File:State_Flag_of_Iran_(1964-1980).svg
License: Public domain
